# Chaos Game & Iterated Function Systems (IFS)

A Python implementation exploring fractal geometry and the **Chaos Game** through linear algebra and affine transformations. Built using `NumPy` and `Matplotlib`, this project demonstrates how simple matrix operations—scaling, rotation, and translation—repeatedly applied to random points converge into complex self-similar structures like the Sierpiński triangle, restricted polygon fractals, and the Barnsley fern.

---

## Mathematical Background

### 1. Affine Transformations in the Chaos Game
Given a regular $n$-gon with vertices $\mathbf{v}_0, \mathbf{v}_1, \dots, \mathbf{v}_{n-1} \in \mathbb{R}^2$ arranged on the unit circle:

$$\mathbf{v}_k = \begin{bmatrix} \cos\left(\frac{2\pi k}{n}\right) \\ \sin\left(\frac{2\pi k}{n}\right) \end{bmatrix}$$

Starting from an initial random point $\mathbf{x}_0 \in \mathbb{R}^2$, each subsequent point $\mathbf{x}_{j+1}$ is generated by selecting a vertex $\mathbf{w} = \mathbf{v}_k$ and applying a linear transformation matrix $T \in \mathbb{R}^{2 \times 2}$ relative to that vertex:

$$\mathbf{x}_{j+1} = T(\mathbf{x}_j - \mathbf{w}) + \mathbf{w}$$

- **Uniform Scaling ($T = rI_2$):** Moves the point a fraction $(1 - r)$ of the distance toward the chosen vertex $\mathbf{w}$. For $n=3$ and $r = \frac{1}{2}$, this produces the classic **Sierpiński Triangle**.
- **Scaling with Rotation ($T = r R(\theta)$):** Combines contraction with a 2D rotation matrix:
  $$R(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}$$

### 2. Vertex Selection Rules
To generate fractals on polygons with $n \ge 4$ vertices (where uniform $r = \frac{1}{2}$ without restrictions simply fills the interior), the simulation supports three selection constraints:
- `"any"`: Selects any vertex $k \in \{0, \dots, n-1\}$ uniformly at random.
- `"not_same"`: Prevents selecting the same vertex twice in a row ($k_{j} \neq k_{j-1}$).
- `"not_opposite"`: Prevents selecting the vertex directly opposite the previous choice ($k_j \neq (k_{j-1} + n/2) \bmod n$, for even $n$).

### 3. Barnsley Fern (Probabilistic IFS)
The `barnsley_fern()` function implements a four-part Iterated Function System where each step applies one of four affine maps $\mathbf{x}_{j+1} = T_i \mathbf{x}_j + \mathbf{q}_i$ according to cumulative probability weights $P = [0.85, 0.92, 0.99, 1.00]$ (modeling stem, successively smaller leaflets, and left/right fronds).

## Usage

Run the main script directly from your terminal:

```bash
python mfad_chaos_game.py
```

### Customizing Experiments
By default, `mfad_chaos_game.py` renders a 4-vertex square chaos game with contraction factor $r = 0.4$ and the `"not_same"` vertex restriction. 

Inside the `if __name__ == "__main__":` block at the bottom of `mfad_chaos_game.py`, you can uncomment the pre-configured experiments to visualize additional fractals:
- **Sierpiński Triangle** ($n=3, r=1/2$)
- **Rotated Triangle Fractal** ($n=3, r=1/2, \theta = \pi/18$)
- **Square Fractals** ($n=4$ with $r=1/3$, `"not_same"`, and `"not_opposite"` rules)
- **Pentagon & Hexagon Fractals** ($n=5, 6$)
- **Barnsley Fern** ($15,000$ iterations)

## Code Structure

| Function | Description |
| :--- | :--- |
| `polygon(n)` | Computes the $(2, n)$ coordinate matrix of a regular $n$-gon inscribed in the unit circle. |
| `rotation(theta)` | Returns a $2 \times 2$ counter-clockwise rotation matrix for angle $\theta$ (in radians). |
| `chaos_game(v, T, num, rule)` | Iteratively computes `num` points using matrix transformation `T` and vertex selection `rule`. |
| `barnsley_fern(num)` | Generates the Barnsley fern using weighted probabilistic affine transformations. |
| `show(pts, v, title)` | Plots the generated point cloud alongside the bounding polygon vertices using Matplotlib. |
